# Simple Python Port Scanner

A basic Python-based network tool designed to scan target IP addresses or hostnames for open TCP ports using Python sockets.

## Features
- Scans specific target IP addresses/hostnames.
- Checks common ports (21, 22, 80, 441, etc.).
- Simple and lightweight implementation for network analysis.
